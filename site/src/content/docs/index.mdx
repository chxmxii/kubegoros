<div class="kg-layers">
  <div>
    <h2>What runs where</h2>
    <p>Every component below lives in <code>kubernetes/apps</code> as an ArgoCD Application. Nodes are the only thing configured outside git.</p>
  </div>
  <dl>
    <dt>network</dt><dd>Cilium with kube-proxy replacement, MetalLB for addresses, Envoy Gateway for HTTPS, NetBird for remote access.</dd>
    <dt>identity</dt><dd>Keycloak is the single login for ArgoCD, Grafana, Headlamp, kubectl and every dashboard without its own auth.</dd>
    <dt>storage</dt><dd>Longhorn with two replicas, hourly snapshots, daily backups to S3 and an encrypted storage class.</dd>
    <dt>signals</dt><dd>Prometheus and Grafana for metrics, Vector and Loki for logs, Hubble for network flows.</dd>
    <dt>secrets</dt><dd>Vault holds them, External Secrets copies them in. Nothing secret is committed.</dd>
  </dl>
</div>

<div class="kg-flow">
  <h2>How a change reaches the cluster</h2>
  <ol>
    <li><strong>Edit</strong><span>Change a values file or manifest under <code>kubernetes/apps</code>.</span></li>
    <li><strong>Merge</strong><span>Renovate opens version bumps the same way, as pull requests.</span></li>
    <li><strong>Sync</strong><span>ArgoCD notices the new commit and applies it in sync-wave order.</span></li>
    <li><strong>Heal</strong><span>Manual drift is reverted. Git stays the source of truth.</span></li>
  </ol>
</div>
