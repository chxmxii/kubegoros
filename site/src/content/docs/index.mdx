<div class="kg-layers">
  <div>
    <h2>Components</h2>
    <p>Each component is an ArgoCD Application under <code>kubernetes/apps</code>. Only the nodes are configured outside git.</p>
  </div>
  <dl>
    <dt>network</dt><dd>Cilium (no kube-proxy), MetalLB, Envoy Gateway, NetBird</dd>
    <dt>identity</dt><dd>Keycloak, used by ArgoCD, Grafana, Headlamp, kubectl and the gateway</dd>
    <dt>storage</dt><dd>Longhorn with snapshots, S3 backups and an encrypted storage class</dd>
    <dt>monitoring</dt><dd>Prometheus, Grafana, Loki, Vector, Hubble</dd>
    <dt>secrets</dt><dd>Vault, synced into the cluster by External Secrets</dd>
  </dl>
